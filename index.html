About

I work on language-model agents that use tools, and on making them small enough to train and run cheaply. My current research asks whether the benefits of tool-token agents, which select a tool from tens of thousands in a single decoding step, can be kept without training one large model to run the entire agent loop. The answer, so far, is yes: splitting the loop where the capabilities differ lets lightweight models rival much larger agents.

I work with Prof. Wenzhuo Zhou at UC Irvine. Before that, I studied software engineering at Dalian University of Technology. I am applying to PhD programs for Fall 2027, with interests in LLM agents, tool learning, and efficient language models.

Research

ToolSIC: Small-Backbone Tool-Token Agents Rivaling Large Models

Tiancong Li, Wenzhuo Zhou. Under review at ACL Rolling Review, October 2026.

one shared transcript, one module active at a time

ToolSIC splits the agent loop at the tool-token interface into three lightweight modules. Select a module to see what it does.

  • Tool-token methods let an agent pick a tool from tens of thousands of APIs in a single decoding step, but existing tool-token agents train one large model to learn the whole tool vocabulary and run the entire agent loop, at substantial training and inference cost.
  • ToolSIC decomposes the agent loop at the tool-token interface into three lightweight modules, Selection, Invocation and Composition, which share a single transcript with only one active at a time.
  • Each module learns only what its task requires. The selection module is taken before trajectory training, so it retains knowledge of the whole tool vocabulary; the invocation module, trained on trajectories, decides when to call a tool and writes the call; the composition module is an off-the-shelf instruction-tuned model that writes the answer without further training.
  • On StableToolBench with 47K tools, ToolSIC, built from models far smaller than the released ToolGen agent, outperforms it in grounded success at a fraction of its training and inference compute. A grounded-success metric, paired statistical tests, a stricter judge and a blind human comparison back the result.

The paper is under anonymous review. I am happy to share the PDF by email.
